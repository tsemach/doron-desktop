# Project Naming

- The product's name is **Ascurix**. "Amicus" and "Doron Desktop" are prior names from before earlier renames.
- When referring to the project in conversation, docs, comments, UI copy, or any other non-resource context, use **Ascurix**.
- Exception: real, physical resources that were provisioned under an old name — the GitHub repo, the local directory path (`doron-desktop`), package names, app identifiers (e.g. `com.tsemach.doron-desktop`), database names, etc. — must keep using `doron-desktop` until they are manually migrated. Do not rename these on your own initiative.
- The `ascurix.com` domain is a live exception to the rule above: it's already provisioned and serving `apps/backend` in production, so it's correct to reference as the real domain (unlike the other still-`doron-desktop` resources).
